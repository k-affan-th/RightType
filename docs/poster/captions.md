# ข้อความโพสต์ RightType

ตัวเลขทุกตัวมาจากโปรเจกต์จริง: ตัวติดตั้ง 3.4 MB (RightType-2.6.1-setup.exe), ~2 µs ต่อปุ่ม
(docs/TYPING_BENCHMARK.md), พจนานุกรม ~150,000 คำใช้ RAM ราว 5.6 MB (CHANGELOG 2.x)
หมายเหตุ: 5.6 MB คือส่วนพจนานุกรม ไม่ใช่ RAM ทั้งโปรแกรม

## แบบสั้น (Facebook / X / Threads)

พิมพ์ไปเลย ภาษาเดี๋ยวแก้ให้

ลืมสลับคีย์บอร์ดจนได้ `แนพพำแะ` แทน `correct` ใช่ไหม
RightType แก้กลับให้ทันที ไม่ต้องลบ ไม่ต้องพิมพ์ใหม่

- ตัวติดตั้งแค่ 3.4 MB เขียนด้วย Rust
- ประมวลผล ~2 ไมโครวินาทีต่อปุ่ม พิมพ์ไม่สะดุด
- ไม่มีโค้ดเครือข่ายเลย ฟรี โอเพนซอร์ส

สแกน QR ในภาพ หรือ https://github.com/k-affan-th/RightType

#RightType #พิมพ์ผิดภาษา #Rust #Windows #โอเพนซอร์ส

## แบบยาว (Pantip / กลุ่มสาย dev)

ทุกวันเรากดสลับภาษาผิดกันคนละหลายครั้ง แล้วต้องลบพิมพ์ใหม่
ผมเลยทำ RightType: แก้ข้อความที่พิมพ์ผิดคีย์บอร์ด ไทย ↔ อังกฤษ ให้เอง

เร็วและเบา
- ตัวติดตั้ง 3.4 MB ไม่ต้องใช้สิทธิ์ admin
- ประมวลผลเฉลี่ย ~2 µs ต่อปุ่ม (วัดไว้ใน docs/TYPING_BENCHMARK.md)
- พจนานุกรมไทย+อังกฤษ ~150,000 คำ ใช้ RAM ราว 5.6 MB

ของเล็ก ๆ ที่ช่วยชีวิต
- พ.ศ. ↔ ค.ศ. และจำนวนเงินเป็นตัวหนังสือ
- Snippets (พิมพ์ `;addr` แล้วเว้นวรรคได้ที่อยู่ทั้งก้อน), สูตรคณิตศาสตร์
- กด Shift สองครั้งเพื่อหาตัวอักษรพิเศษ
- ตั้งโหมดแยกตามแอป (VS Code ไม่แตะชื่อตัวแปร)
- Ctrl+Backspace ลบทีละคำไทย
- โหมดฝึกพิมพ์ Kedmanee / Pattachote / Manoonchai

ไว้ใจได้
- ไม่มีโค้ดเครือข่าย ตรวจได้จาก Cargo.lock
- ไม่บันทึกสิ่งที่พิมพ์ ปิดตัวเองในช่องรหัสผ่าน

https://github.com/k-affan-th/RightType
