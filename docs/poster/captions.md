# ข้อความโพสต์ RightType

ตัวเลขทุกตัวมาจากโปรเจกต์จริง วัดจาก release 2.6.1 (ตรวจขนาดตัวติดตั้งใหม่เมื่อ 2.6.2 build เสร็จ):

- ตัวติดตั้ง 3.4 MB: `RightType-2.6.1-setup.exe` = 3,572,544 ไบต์ (หน้า Releases)
- ~2 µs ต่อปุ่ม: `docs/TYPING_BENCHMARK.md` (เฉลี่ย ช้าสุด ~2.4 ms)
- คำไทย 60,964 คำและวลี 200,000 วลีที่พิมพ์ถูก แปลงผิด 0: false-positive audit
  ใน `docs/TYPING_BENCHMARK.md` (ทดสอบกับพจนานุกรมที่ติดมากับแอป ไม่ใช่การพิมพ์จริง)
- ไม่มีโค้ดเครือข่าย: ตรวจได้จาก `Cargo.lock`

ยังไม่มี: RAM ของโปรแกรมทั้งตัวของ release build (วัดแล้วเป็น debug build เท่านั้น) จึงไม่ควรโพสต์ว่ากิน RAM เท่าไร
ช่องทางติดตั้งตอนนี้มีทางเดียว คือดาวน์โหลดจากหน้า Releases (ยังไม่มี winget)

## แบบสั้น (Facebook / Threads / Instagram)

พิมพ์ไปเลย ภาษาเดี๋ยวแก้ให้

เคยไหม พิมพ์มาทั้งประโยค เงยหน้าดูอีกที ได้ `แนพพำแะ` แทน `correct`
RightType แก้กลับให้ทันที ไม่ต้องลบ ไม่ต้องพิมพ์ใหม่ ทั้งไทย → อังกฤษ และอังกฤษ → ไทย

- ตัวติดตั้งแค่ 3.4 MB เขียนด้วย Rust
- ประมวลผล ~2 ไมโครวินาทีต่อปุ่ม พิมพ์ไม่สะดุด
- ไม่มีโค้ดเครือข่าย ไม่บันทึกสิ่งที่พิมพ์ ปิดตัวเองในช่องรหัสผ่าน
- ฟรี โอเพนซอร์ส ไม่ต้องใช้สิทธิ์ admin

สแกน QR ในภาพ หรือโหลดที่ https://github.com/k-affan-th/RightType/releases/latest

#RightType #พิมพ์ผิดภาษา #Rust #Windows #โอเพนซอร์ส

**คอมเมนต์แรก (ปักหมุด):** ไฟล์ยังไม่ได้ลงลายเซ็นดิจิทัล Windows จึงขึ้นหน้าเตือนสีน้ำเงิน
ให้กด More info → Run anyway ได้ และตรวจไฟล์เทียบ `SHA256.txt` ในหน้าเดียวกันได้

## แบบยาว (Pantip / กลุ่มสาย dev / Reddit)

**RightType: โปรแกรมแก้ข้อความที่พิมพ์ผิดภาษา ไทย ↔ อังกฤษ ฟรีและโอเพนซอร์ส**

ทุกคนต้องเคยลืมสลับคีย์บอร์ด แล้วต้องลบพิมพ์ใหม่ ผมทำ RightType เพื่อเรื่องนี้โดยเฉพาะ
ต่อยอดจากแนวคิดของ RightLang แต่เขียนใหม่ด้วย Rust

**ใช้ยังไง**
- โหมดปกติ กด Shift+Backspace แก้คำล่าสุด กดซ้ำเพื่อย้อนไปได้ถึง 8 คำ
- โหมด Auto แก้และสลับภาษาให้เอง โหมด Suggest แสดงคำที่แก้แล้วข้างเคอร์เซอร์ กด Tab เพื่อใช้
- ตั้งโหมดแยกตามแอปได้ เช่น ใน VS Code ไม่แตะชื่อตัวแปร

**ต่างจากตัวอื่นตรงไหน**
- ไม่ย้ำปุ่มซ้ำ ใส่ตัวอักษรที่ถูกให้ทีเดียว จึงไม่มี `ggg…` โผล่ และไม่ตกหล่นใน Word
- ตื่นแล้วทำต่อ เครื่องหลับหรือล็อกจอแล้วกลับมาก็ยังทำงาน ไม่ต้องปิดเปิดโปรแกรม
- ไม่แก้คำที่ถูกให้ผิด ทดสอบกับพจนานุกรมที่ติดมากับแอป คำไทย 60,964 คำและวลี 200,000 วลีที่พิมพ์ถูก แปลงผิด 0
  (เป็นการทดสอบกับชุดข้อมูล ไม่ใช่การรับประกัน)
- เบา ตัวติดตั้ง 3.4 MB ประมวลผลเฉลี่ย ~2 µs ต่อปุ่ม

**ของเล็ก ๆ ที่ช่วยชีวิต**
พ.ศ. ↔ ค.ศ., จำนวนเงินเป็นตัวหนังสือ, Snippets (พิมพ์ `;addr` เว้นวรรคได้ที่อยู่ทั้งก้อน), สูตรคณิตศาสตร์,
กด Shift สองครั้งเพื่อหาอักขระพิเศษ, ลบทีละคำไทยด้วย Ctrl+Backspace, โหมดฝึกพิมพ์ Kedmanee / Pattachote / Manoonchai

**ความเป็นส่วนตัว (โปรแกรมคีย์บอร์ดเห็นทุกอย่างที่พิมพ์ จึงสำคัญ)**
- ไม่มีโค้ดเครือข่ายเลย ตรวจได้จาก Cargo.lock
- ไม่บันทึกสิ่งที่พิมพ์ลงดิสก์
- ปิดตัวเองในช่องรหัสผ่าน, password manager, กระเป๋าคริปโต, terminal, remote desktop และเกมเต็มจอ
- ไม่ต้องใช้สิทธิ์ admin

**ข้อจำกัด (บอกตรง ๆ)**
- คำสั้นที่กำกวมจริง ๆ เช่น `ok` กับ `นา` ที่กดปุ่มเดียวกัน โปรแกรมไม่เดา ต้องแก้เองด้วย Shift+Backspace
- ตอนนี้มีเฉพาะ Windows และไฟล์ยังไม่ได้ลงลายเซ็นดิจิทัล จึงมีหน้าเตือน SmartScreen (ตรวจ SHA-256 ได้)
- ตอนนี้ติดตั้งผ่านหน้า Releases ทางเดียว
