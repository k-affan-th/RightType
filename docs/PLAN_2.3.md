# แผน RightType 2.3: ฝึกพิมพ์และย้ายแป้น (ร่าง)

สถานะ: ร่างเพื่อให้เจ้าของตัดสินใจ ยังไม่เริ่มทำ ข้อที่ต้องเลือกมีเครื่องหมาย ★

## ทำไมต้องเป็นเรื่องนี้

ตั้งแต่ 1.x ถึง 2.2 RightType ช่วย **หลังพิมพ์ผิดแล้ว** คือแก้คำที่พิมพ์ผิดแป้น และเตือนเรื่อง CapsLock, NumLock, Insert
2.3 ขยับไปช่วย **ก่อนพิมพ์ผิด** คือทำให้คนพิมพ์คล่องขึ้นจนผิดน้อยลงเอง

ฐานที่มีอยู่แล้ว ไม่ต้องสร้างใหม่:
- ตารางแป้นสามแบบ: เกษมณี ปัตตะโชติ มนูญชัย (`src/layout/`)
- หน้าต่างแป้นพิมพ์บนจอ (`keymap.rs`, Ctrl+Alt+K)
- พจนานุกรมไทยและอังกฤษในตัว ใช้สร้างแบบฝึกได้โดยไม่ต้องใช้ข้อความของผู้ใช้
- overlay, palette และหน้าตั้งค่าที่มีระบบธีมกับ DPI ครบแล้ว

## สิ่งที่ไม่ทำ (ยืนยันจากการคุยวันที่ 2026-10-02)

- **ไม่มีการเชื่อมต่อเครื่องอื่น** ทั้งส่งการพิมพ์ออกและรับเข้า เพราะต้องใช้เครือข่าย ตัวดักแป้นพิมพ์ที่ส่งข้อมูลออกได้ก็คือรูปแบบของ keylogger
- **ไม่มีตารางคะแนนออนไลน์** และไม่มีบัญชีผู้ใช้
- ไม่มีโค้ดเครือข่ายเหมือนเดิม (CI ตรวจ)

| รหัส | ฟีเจอร์ | ผู้ใช้ได้อะไร | ขนาดงาน |
|---|---|---|---|
| T1 | **หน้าต่างฝึกพิมพ์** | บทเรียนทีละแถวแป้น (แถวเหย้า แถวบน แถวล่าง Shift) วัดความเร็ว (คำ/นาที, ตัวอักษร/นาที) และความแม่นยำ เลือกได้ทั้งเกษมณี ปัตตะโชติ มนูญชัย และอังกฤษ | ใหญ่ |
| T2 | **แบบฝึกจากพจนานุกรม** | ข้อความฝึกสุ่มจากคำจริงในพจนานุกรมในตัว คัดเฉพาะคำที่ใช้แป้นซึ่งปลดล็อกแล้ว ไม่ใช้ข้อความที่ผู้ใช้พิมพ์ | กลาง |
| T3 | **ฝึกเฉพาะจุด (ปุ่มที่ผิดบ่อย)** | ระหว่างฝึกนับว่าปุ่มไหนกดผิดหรือช้า แล้วรอบถัดไปเน้นปุ่มนั้น ★ | กลาง |
| T4 | **เกม** | (ก) แข่งกับเวลา 60 วินาที (ข) คำตกจากบนจอต้องพิมพ์ให้ทันก่อนถึงพื้น (ค) streak ห้ามผิด ทุกเกมเล่นด้วยแป้นอย่างเดียว ★ เลือกว่าจะเอากี่แบบ | กลาง–ใหญ่ |
| T5 | **โหมดย้ายไปมนูญชัย / ปัตตะโชติ** | เปิดแป้นบนจอแบบใหม่ค้างไว้ระหว่างพิมพ์งานจริง ไฮไลต์ปุ่มที่เพิ่งกด ค่อยๆ ซ่อนปุ่มที่คล่องแล้ว | กลาง |
| T6 | **แผนที่ความร้อนบนแป้น** | แป้นบนจอแสดงสีตามอัตราผิดของแต่ละปุ่ม (จากการฝึกเท่านั้น) | เล็ก |
| T7 | **แบบฝึกเฉพาะภาษาไทย** | ลำดับสระ–วรรณยุกต์ (ป้องกัน `ี่` กับ `่ี` สลับกัน) ตัวที่ต้องใช้ Shift เลขไทย ฯ ๆ | เล็ก–กลาง |
| T8 | **ความคืบหน้า** | กราฟความเร็วและความแม่นยำรายวัน เป้ารายวัน ★ เก็บหรือไม่เก็บ | กลาง |
| S1 | **หน้าตั้งค่า "แป้นพิมพ์"** | ย้ายสวิตช์ที่ตอนนี้อยู่แค่ใน palette มาไว้ในหน้าเดียว: ที่อยู่เว็บ/ตัวเลข ตัวหนอน NumLock Insert แท็กรหัสผ่าน เปลี่ยนภาษากลับเมื่อกดพร้อมปุ่มลัด เติมคำไทย และย้ายตัวเลือกแป้นไทยมาจากหน้าปุ่มลัด | กลาง |

## ข้อมูลที่เก็บ (ตาม THREAT_MODEL)

| ข้อมูล | เก็บไหม | หมายเหตุ |
|---|---|---|
| ข้อความที่พิมพ์ระหว่างฝึก | **ไม่เก็บ** | อยู่ในหน่วยความจำระหว่างบทเรียน แล้ว zeroize เมื่อจบ |
| ข้อความที่พิมพ์ในแอปอื่น | **ไม่ใช้เลย** | การฝึกไม่อ่านการพิมพ์จริง |
| จำนวนครั้งที่ผิดต่อปุ่ม (T3, T6) | ★ | metadata เป็นตำแหน่งปุ่มกับจำนวนครั้ง ไม่มีลำดับ จึงประกอบกลับเป็นคำไม่ได้ |
| คะแนนรายวัน (T8) | ★ ต้องเปิดเอง | วันที่, บทเรียน, ความเร็ว, ความแม่นยำ เก็บไม่เกิน 365 แถว |

## ข้อที่ต้องตัดสินใจ ★

1. **T3/T6 สถิติปุ่ม:** นับจากการฝึกเท่านั้น (แนะนำ) หรือนับจากการพิมพ์จริงด้วย
   - การพิมพ์จริงทำให้แม่นกว่า แต่เท่ากับดูทุกปุ่มที่กดตลอดเวลา แม้จะไม่เก็บลำดับก็ตาม
   - ผมแนะนำให้นับจากการฝึกเท่านั้น ตามหลัก "ลดการเก็บข้อมูลให้มากที่สุด"
2. **T8 ความคืบหน้า:**
   - (ก) ไม่เก็บเลย แสดงแค่ผลรอบปัจจุบัน
   - (ข) เก็บคะแนนรายวันเมื่อผู้ใช้เปิดเอง (แนะนำ)
3. **T4 เกม:** เอาทั้งสามแบบ หรือเริ่มที่ "แข่งกับเวลา" กับ "คำตก" ก่อน (แนะนำ)
4. **ที่อยู่ของหน้าฝึก:**
   - (ก) หน้าต่างแยกที่เปิดจาก tray, palette และ Ctrl+Alt+T (แนะนำ)
   - (ข) หน้าใหม่ในหน้าตั้งค่า

## ลำดับงาน

1. **S1 + S2** หน้าตั้งค่า "แป้นพิมพ์": ยังเป็นงานแก้แป้นเดิม และตอบเรื่องสวิตช์ที่อยู่เว็บใน Settings ซึ่ง 2.2.0 ใส่ไม่ได้เพราะหน้า General เต็ม
2. **แกนการฝึก (OS-free, `src/trainer/`):**
   - สร้างบทเรียนจากตารางแป้นและพจนานุกรม
   - ให้คะแนน คิดความเร็วและความแม่นยำ
   - unit test ทั้งหมด: บทเรียนทุกแป้นใช้เฉพาะปุ่มที่ปลดล็อก ทุกคำ round-trip ได้
3. **T1 หน้าต่างฝึก + T7:**
   - ใช้ระบบวาดเดียวกับ palette
   - ภาพ Wine ทั้ง TH/EN, สว่าง/มืด, 96/144 DPI
4. **T2 + T3 + T6**
5. **T4 เกม**
6. **T5 โหมดย้ายแป้น + T8**
7. **ปล่อย 2.3.0:** CHANGELOG, THREAT_MODEL, README, ภาพหน้าจอ, e2e

- `cargo fmt --check`
- clippy `-D warnings` บน Linux และ Windows
- `cargo test`

- หน้าต่างฝึก: ระหว่างที่โฟกัสอยู่ในหน้าต่างฝึก hook ต้องไม่แก้คำ เพราะเป็นการฝึก การแก้ให้จะทำให้ผลการฝึกผิด มีเคส e2e ยืนยัน
- ไม่มีโค้ดเครือข่าย (CI ตรวจเหมือนเดิม)
