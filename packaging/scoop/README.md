# RightType Scoop Packaging & Custom Bucket

This directory contains resources and documentation for distributing RightType via [Scoop](https://scoop.sh/), the command-line package manager for Windows.

## Overview

RightType distributes Scoop manifests targeting its standalone, portable zip packages (`RightType-<version>-x64.zip` and `RightType-<version>-arm64.zip`).

The manifest generator script `packaging/scoop.ps1` produces a valid `righttype.json` manifest that can be hosted in a personal Scoop bucket or submitted upstream to official buckets.

---

## Hosting in Custom Bucket (`k-affan-th/scoop-bucket`)

To host RightType in a dedicated Scoop bucket:

### 1. Bucket Repository Structure

Create or maintain a GitHub repository named `k-affan-th/scoop-bucket` structured as:

```text
scoop-bucket/
├── .github/
│   └── workflows/
│       └── excava.yml        # Optional: Automated checkver / autoupdate
├── bucket/
│   └── righttype.json       # Generated Scoop manifest
└── README.md
```

### 2. Updating the Manifest

When a new version is released:

```powershell
# From the RightType repository root:
pwsh -File packaging/scoop.ps1 -Version <version>
```

Copy the generated manifest:

```powershell
Copy-Item dist/scoop/righttype.json ../scoop-bucket/bucket/righttype.json
```

Commit and push to `k-affan-th/scoop-bucket`.

Because `righttype.json` includes `checkver: "github"` and `autoupdate` directives, automated bucket bots (like Scoop's GitHub Actions Excavator bot) can also detect new releases and update hashes automatically.

## User Installation

Users can install RightType via Scoop in two simple commands:

```powershell
# 1. Add the custom bucket
scoop bucket add righttype https://github.com/k-affan-th/scoop-bucket

# 2. Install RightType
scoop install righttype
```

### Updating

To update RightType to the latest version:

```powershell
scoop update
scoop update righttype
```

### Uninstalling

```powershell
scoop uninstall righttype
```

## Path to Official `ScoopInstaller/Extras`

Scoop maintains official buckets, with GUI applications and non-developer tools categorized under [ScoopInstaller/Extras](https://github.com/ScoopInstaller/Extras).

### Submission Criteria

Per Scoop's community inclusion policy, software submitted to `ScoopInstaller/Extras` must meet these criteria:
1. **Popularity & Traction:** A minimum threshold of community interest (traditionally ~100 GitHub stars).
2. **Portability:** Installs cleanly without requiring global system changes or forced admin privileges. RightType's portable zip format and user-level execution satisfy this requirement.
3. **Active Maintenance:** Regular releases, documented licenses (MIT/Apache-2.0), and a public issue tracker.

### Upstream Submission Steps (at 100 stars milestone)

1. Fork [ScoopInstaller/Extras](https://github.com/ScoopInstaller/Extras).
2. Add `bucket/righttype.json` (generated by `packaging/scoop.ps1`).
3. Validate locally:
   ```powershell
   ./bin/checkver.ps1 righttype
   ./bin/formatjson.ps1 righttype
   ./bin/test.ps1 -TestPath test/manifest/righttype.tests.ps1
   ```
4. Open a pull request against `ScoopInstaller/Extras`.
5. Once merged, users can install directly via:
   ```powershell
   scoop bucket add extras   # If not already added
   scoop install righttype
   ```
